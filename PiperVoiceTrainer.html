Voice source

Connect ElevenLabs, choose the voice to capture, and freeze its settings. A training set needs the same voice, model, settings and seed for every clip — consistency beats expressiveness here.

API key

The key is only sent to api.elevenlabs.io.

Voice and model

Multilingual v2 is the safest choice for datasets: stable timbre and good seed reproducibility. v3 is more expressive but drifts more between clips.

Frozen generation settings

Good dataset defaults: stability 0.55–0.75, similarity 0.75–0.85, style 0, speed 1.0. Don't change these once generation starts, or the model learns two slightly different voices.

Preview

Before building a dataset, confirm your ElevenLabs plan and terms allow using generated audio to train another model, and that you have rights to the voice.

Text corpus

Collect far more sentences than you need, clean them so the text matches exactly what will be spoken, then pick a balanced script that covers many words and sound patterns.

Source text

Good sources: public-domain books (Project Gutenberg, Wikisource), your own writing, and the kinds of phrases your app will actually speak. Aim for a pool 3–5 times the size you need.

Candidate pool

Pick a balanced script

Sentences that add new words and letter patterns are picked first, with extra weight for questions and exclamations. 60–120 minutes is a strong fine-tuning set; 30 minutes is a workable minimum.

Project script

Generate speech

Each sentence is sent to ElevenLabs with the frozen settings and saved in this browser as raw 16-bit PCM. Checks run on every clip as it arrives. You can stop and resume at any time.

Log

Automatic checks

Every clip is measured for silence, clipping, loudness and pauses, then trimmed and normalized on export. Speaking rate is compared against the whole set: a clip that is much faster or slower than its text implies usually has skipped, repeated or invented words.

Thresholds

Transcript check

Sends clips to ElevenLabs speech-to-text and compares the transcript with the script. This catches mispronunciations and hallucinated words the rate check misses. It uses speech-to-text credits.

Results

Listen and decide

Hear every flagged clip, and spot-check the rest. Reject anything with a wrong word, odd emphasis, breath noise or a change in voice character. When the audio says something slightly different from the script, fix the text instead.

Export dataset

Builds a ZIP with trimmed, loudness-matched 16-bit mono WAVs, metadata for both Piper versions, a QC report, test sentences and ready-to-run training scripts.

Start over

Deletes all sentences, audio and review decisions stored in this browser. Settings and the API key stay.

Fine-tune and export ONNX

Training runs on a Linux machine with an NVIDIA GPU (8 GB VRAM minimum, 24 GB comfortable). These scripts are also inside the ZIP. They fine-tune from the Lessac medium checkpoint using the maintained piper1-gpl repository, since the original rhasspy/piper repo is archived.

Training settings

Fine-tuning resumes the checkpoint's epoch counter, so the training limit is its epoch plus your extra epochs. About 1,000 extra epochs is typical; stop earlier once loss_disc_all in TensorBoard levels off and test clips stop improving. The checkpoint can be from another language — that's normal for Hindi, Marathi and others.
